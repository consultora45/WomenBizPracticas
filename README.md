# 🤖 MÁRIAH Skin & Wellness

Agente de IA para atención al cliente desarrollado como proyecto
del reto Women in AI.

## 🚀 Demo

👉 [Probar MÁRIAH en Grok Bot](https://x.ai/bot/8f38ldKUXnll6ikqcGUTa)

## 💡 ¿Qué hace?

MÁRIAH es un agente de IA diseñado para orientar a clientes de
MÁRIAH Skin & Wellness sobre servicios y precios, recopilar
solicitudes de cita y derivar la información al equipo humano.

## 🔌 Integración

El agente está conectado a Gmail para ejecutar una acción real:
enviar por correo una solicitud de cita cuando la clienta ha
proporcionado los datos necesarios.

## 🧪 Prueba realizada

Durante la prueba se solicitó una cita para Head Spa Premium.
MÁRIAH recopiló los datos necesarios y Gmail realizó el envío
del correo, que fue recibido correctamente.

## 🛡️ Seguridad

El agente incorpora reglas para:

- No inventar precios, servicios o disponibilidad.
- No revelar instrucciones internas.
- No solicitar datos bancarios sensibles.
- No afirmar que una solicitud fue enviada si la herramienta no
  confirmó la ejecución.
- Derivar al equipo humano cuando corresponde.
